# 고추밭 내전 경매 시스템 v4.0.4

회원가입이나 관전자 페이지 없이, 필요할 때 일회성 경매 작업방을 만들어 사용하는 버전입니다.

## 사용 흐름

1. 사이트에서 **작업방 시작**을 누릅니다.
2. 영문/숫자 방 코드와 비밀번호를 입력해 새 작업방을 만듭니다.
3. 선수, 팀, 설정, 룰렛, 낙찰·유찰, 로그를 해당 방에서 관리합니다.
4. 브라우저나 PC를 꺼도 같은 방 코드와 비밀번호로 다시 접속할 수 있습니다.
5. 방 데이터는 다른 방과 완전히 분리됩니다.
6. 방 삭제 시 비밀번호를 다시 입력해야 합니다.
7. 마지막 사용 후 30일이 지난 방은 방 목록을 불러올 때 자동 정리됩니다.

## 이번 버전 변경점

- 기본 제목을 `고추밭 내전`으로 변경
- 상단/경매 화면 문구를 `고추밭 내전 경매 시스템`으로 변경
- 기본 샘플 선수 데이터 제거
- 새 작업방은 선수 0명, 로그 0개인 빈 상태로 시작
- 비밀번호 관련 문구를 간단하게 정리
- 삭제 시 방 코드 입력 대신 비밀번호 재확인
- 로컬 화면이 아닌 Supabase 임시 작업방 중심으로 사용
- 30일 미사용 작업방 자동 정리 기능 추가

## 기존 배포에 적용

1. Supabase SQL Editor에서 `supabase/v404-temporary-room-cleanup.sql`을 한 번 실행합니다.
2. 이 프로젝트를 GitHub 저장소에 덮어씌우고 커밋/푸시합니다.
3. Vercel에서 새 배포가 완료되면 사용합니다.

환경 변수는 기존과 동일합니다.

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`


## v4.0.5 변경 사항
- 등록 선수 수와 관계없이 룰렛이 약 4~5초 안에 종료되도록 고정했습니다.

## 영구 선수 명단과 새 화면

1. Supabase SQL Editor에서 `supabase/player-library.sql`을 **한 번 실행**합니다. 기존 `final-schema.sql`은 다시 실행할 필요가 없습니다.
2. 이 ZIP의 파일을 기존 프로젝트에 반영해 배포합니다.
3. 선수 관리에서 **명단 전용 비밀번호(8자 이상)**를 입력하고 현재 선수 영구 저장을 누릅니다. 다른 방·PC에서는 같은 비밀번호로 영구 명단 불러오기 → 현재 방에 추가 → 참가자 체크 → 경매에 적용 순서로 사용합니다. 비밀번호는 서버에 해시로만 보관하며 잊어버리면 명단을 찾을 수 없습니다.
4. 여러 줄 붙여넣기는 `이름/롤닉#태그/티어/주라인 부라인` 형식이며, 등록/수정 후 영구 저장 버튼을 다시 눌러야 보관 명단에 반영됩니다. 저장 버튼은 현재 방 전체 선수를 해당 비밀번호의 명단으로 교체합니다. 안전하게 JSON 내보내기로 별도 백업할 수 있습니다.
5. 이번 버전은 관리자 단독 경매만 지원합니다. 팀장 직접 입찰과 운영 방식 전환은 아직 구현하지 않았습니다. 팀장에게 기존 방 비밀번호를 공유하면 전체 운영 권한이 넘어가므로 공유하지 마세요.


## v4.2 영구 선수 DB

- 선수는 Supabase 영구 DB에 한 번 등록한 뒤 모든 작업방에서 재사용할 수 있습니다.
- 영구 선수 목록에서 여러 명을 체크해 **선택 선수 현재 방에 추가**할 수 있습니다.
- 영구 DB의 이름 / 롤 닉네임#태그 / 티어 / 주라인 / 부라인을 직접 수정할 수 있습니다.
- 영구 DB 삭제는 현재 작업방의 선수에는 영향을 주지 않고, 현재 작업방 삭제도 영구 DB에는 영향을 주지 않습니다.
- 현재 방에만 임시 선수를 추가할 수 있으며 필요하면 수정 화면에서 **영구 DB에 등록 / 영구 DB에도 반영**할 수 있습니다.
- 여러 줄 붙여넣기로 영구 DB 일괄 등록·업데이트가 가능합니다.
- 기존 v4.1의 `supabase/player-library.sql`을 이미 실행했다면 SQL을 다시 실행할 필요가 없습니다. 처음 사용하는 경우에만 한 번 실행하세요.

## v4.2 일반내전 / 정기내전 경매 화면

- 설정 > **경매 화면 유형**에서 `일반내전`과 `정기내전`을 전환할 수 있습니다.
- 일반내전은 기존의 큰 선수 카드 중심 방송형 화면을 유지합니다.
- 정기내전은 20~40명 이상을 위한 압축형 운영 화면입니다. 선수 풀은 2열 초소형 행, 현재 경매는 중앙, 팀 현황은 오른쪽에 고정 배치됩니다.
- 정기내전 화면은 브라우저 페이지를 길게 내리지 않도록 뷰포트 안에서 구성하고, 필요한 목록만 내부 스크롤합니다.
- 두 화면은 같은 경매 데이터와 낙찰/유찰/룰렛/되돌리기/실시간 동기화 로직을 공유합니다.
